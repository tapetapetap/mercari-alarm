# Contract: 관리 화면 접근 제한 (변경분)

001의 [web-api](../../001-keyword-alarm/contracts/web-api.md)에 아래 규칙을 **먼저** 적용한다.

| 요청한 쪽 IP | 처리 |
|---|---|
| `127.0.0.0/8` (맥북 자신) | 기존대로 |
| `100.64.0.0/10` (Tailscale) | 기존대로 |
| 그 외 (같은 와이파이의 다른 기기 등) | 모든 경로·메서드에 `403` (본문 없음) |

이후 Host 검사(`403`), 경로·메서드 처리는 001과 같다.
