# Feature Specification: 번역 차단 대응

**Feature Branch**: `003-translate-fallback`

**Created**: 2026-10-11

**Status**: Draft

(1) 번역 주소를 지금 이 맥북에서 동작하는 clients5.google.com/translate_a/t?client=dict-chrome-ex 로 바꾸고, (2) 429(차단)를 받으면 일정 시간 번역 요청을 쉬어 차단이 길어지지 않게 한다. 실패 시 원문 알림은 그대로 유지. 비용 0, 새 의존성 없음. 브랜치는 002-macos-runtime 위에서 시작(아직 develop 미머지)."

> 001-keyword-alarm의 번역 동작(번역문 + 가격 + 원문, 실패 시 원문·가격)은 그대로다.
> 이 명세는 **번역 서비스가 막혔을 때의 동작**만 다룬다.

## 배경 (2026-10-11 관찰)

- 10/9 13:07부터 번역 48건 실패, 그중 47건이 "요청이 너무 많음(429)". 이후 알림은 원문으로만 왔다.
- 같은 시점 같은 맥북에서 구글의 다른 무료 번역 주소는 정상 응답했다.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 알림을 다시 한국어로 받기 (Priority: P1)

사용자는 새 상품 알림을 다시 "번역된 상품명 / 가격 / (원문)" 형태로 받는다.

**Why this priority**: 지금 번역이 사실상 꺼져 있다. 이것만 고쳐도 원래 기능이 돌아온다.

**Independent Test**: 수정본을 실행 중인 알림기에 반영한 뒤 첫 새 상품 알림이 한국어 번역과 원문을 함께 보여주는지 본다.

**Acceptance Scenarios**:

1. **Given** 번역 서비스가 정상, **When** 새 상품 알림을 보냄, **Then** 본문이 번역문·가격·(원문) 세 줄이다.
2. **Given** 번역 서비스가 오류를 냄, **When** 새 상품 알림을 보냄, **Then** 알림은 원문·가격 두 줄로 지연 없이 간다 (기존 동작).

---

### User Story 2 - 차단당하면 잠시 쉬기 (Priority: P2)

번역 서비스가 "요청이 너무 많다"고 거절하면 알림기는 한동안 번역을 시도하지 않고 원문으로 알린다.
쉬는 시간이 끝나면 다시 번역을 시도한다.

**Why this priority**: 막힌 상태에서 계속 요청하면 차단이 길어지고, 매 상품마다 번역을 기다리느라 알림이 늦어질 수 있다.

**Independent Test**: 번역 서비스가 429를 돌려주는 상황을 흉내 내어, 이후 쉬는 시간 동안 번역 요청이 나가지 않고 그 뒤에는 다시 나가는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 번역 요청이 "요청이 너무 많음"으로 거절됨, **When** 이후 1시간 안에 새 상품 알림을 보냄,
   **Then** 번역 요청을 보내지 않고 원문으로 알린다.
2. **Given** 쉬는 시간 1시간이 지남, **When** 새 상품 알림을 보냄, **Then** 다시 번역을 시도한다.
3. **Given** 다른 종류의 오류(시간 초과, 연결 끊김), **When** 다음 상품 알림, **Then** 쉬지 않고 바로 번역을 시도한다 (일시적 오류로 본다).
4. **Given** 차단을 받음, **Then** 로그에 쉬기 시작했다는 기록이 한 번 남는다 (쉬는 동안 상품마다 경고를 반복하지 않는다).

### Edge Cases

- 번역 결과가 원문과 같거나 비어 있음 → 기존처럼 원문·가격 두 줄.
- 알림기가 재시작됨 → 쉬는 시간은 기억하지 않고 바로 번역을 시도한다 (한 번 더 429를 받으면 다시 쉰다).
- 새 주소도 막힘 → 이 명세의 쉬기 동작으로 원문 알림이 유지된다. 다른 주소로 바꾸는 것은 다음 작업.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-201**: 상품명 번역은 이 맥북에서 현재 동작하는 무료 번역 주소를 사용해 일본어를 한국어로 바꾼다.
- **FR-202**: 번역 서비스가 "요청이 너무 많음"으로 거절하면 1시간 동안 번역 요청을 보내지 않는다.
- **FR-203**: 쉬는 동안과 번역 실패 시 알림은 원문·가격으로 지연 없이 보낸다.
- **FR-204**: 차단으로 쉬기 시작할 때 로그에 한 번 기록한다.
- **FR-205**: 그 외 오류는 기존처럼 상품별로 로그에 남기고 쉬지 않는다.
- **FR-206**: 추가 비용·새 의존성 없음.

## Success Criteria *(mandatory)*

- **SC-201**: 반영 후 첫 하루 동안 개별 알림의 90% 이상이 한국어 번역을 포함한다 (번역 서비스가 정상일 때).
- **SC-202**: 차단을 받은 뒤 1시간 동안 번역 요청이 0건이다.
- **SC-203**: 차단 중에도 새 상품 알림이 차단 전과 같은 시간 안에(1~2분) 도착한다.

## Assumptions

- 번역 주소는 계속 비공식 무료 주소다. 언제든 막힐 수 있고, 그때는 원문 알림으로 버틴다 (intent의 비용 0 원칙).
- 쉬는 시간 1시간은 추정치다. 구글 차단은 보통 수십 분~수 시간 지속된다.
- 쉬는 상태는 파일에 저장하지 않는다 (재시작은 드물다).
