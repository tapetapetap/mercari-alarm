# Quickstart: 번역 차단 대응 확인

## 1. 테스트 (네트워크 없음)

```bash
~/mercari-alarm/.venv/bin/python -m unittest -v
```

기대: 모두 통과 (번역 응답 파싱, 429 후 1시간 쉬기, 다른 오류는 안 쉼 포함).

## 2. 반영

PR 머지 후 [002 quickstart](../002-macos-runtime/quickstart.md)의 "새 코드 반영" 절차.

## 3. 실사용 확인

| 확인 | 방법 | 기대 결과 |
|---|---|---|
| 번역 복구 | 반영 후 첫 새 상품 알림 | 본문이 번역문·가격·(원문) 세 줄 |
| 실패 로그 | `grep "번역" ~/mercari-alarm/alarm.log \| tail` | 반영 이후 `번역 실패`가 거의 없음 |
| 차단 시 | 로그에 `번역 차단(429)` 경고 | 이후 1시간 동안 `번역 실패` 줄이 없고 알림은 원문으로 옴 |
